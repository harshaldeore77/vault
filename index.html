Set up Google Drive

Connect to Google Drive so your vault opens and saves directly in the cloud. Requires a free Google OAuth Client ID (~5 min setup).

1Go to console.cloud.google.com and sign in.
2Create a new project — name it anything (e.g. MyVault).
3APIs & Services → Library → enable Google Drive API.
4APIs & Services → OAuth consent screen → External → fill app name + email → Save.
5Credentials → OAuth client ID → Web application → add Authorised JavaScript origin:
http://localhost:8080
6Copy the Client ID and paste below.
